# arc9

arc9 以唯讀方式審查。依本檔位置解析[審查契約](references/review.md)與[編輯契約](references/output.md)的絕對路徑。

1. **準備。** 主模型載入編輯契約，整理使用者原始請求、已接受的限制與調整、可用材料、可讀範圍與允許的唯讀查證，以及使用者明示的審查範圍、證據門檻與必查事項。
2. **派送。** 以 `fork_turns: "none"` 啟動一位獨立審查者，提供上述資料，請其讀取審查契約。
3. **等待與補查。** 開始等待前設定本次總期限，初審與補查共用，每次等待以剩餘時間為上限。有新增可查材料、前提改變，或有前次漏做且可完成的分析時，才把要補的項目一併交回同一位審查者。同一缺口在材料與前提未變時只補查一次。
4. **收尾。** 審查完成、無法再取得結果或到期時，分清已有結論和依據、已查仍缺證而能指出缺口及影響，以及尚未審查的問題。有前兩類仍適用的回答時才交給編輯，並標明尚未審查的問題。否則回報受阻與原因。
