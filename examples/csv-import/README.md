# CSV 匯入：舊版三組回答

這份歷史案例使用舊版 simplicity 與 reliability。方案只需要 CSV，卻預留多格式架構並加入佇列；失敗會整批重試，也可能與修正後的匯入同時執行。

[共同材料與問題](input.md)。

| 引導方式 | 回答中的安排 | 完整回答 |
|---|---|---|
| 資深工程師角色提示 | 先說明覆寫與完成狀態的風險，再縮小方案，確認新舊判準與人工修改是否也要保護。 | [原文](baseline.md) |
| simplicity | 先簡化流程，再提出以受理順序保存序號的條件式安排，並指出鎖定成本需要量測。 | [原文](single.md) |
| simplicity ＋ reliability | 確認是否允許部分成功，分開說明交易如何保護提交一致性、版本條件如何阻止舊資料覆寫。 | [原文](dual.md) |

三份回答都建議暫緩格式工廠、量測後再決定是否使用佇列，並驗證中斷、重試與新舊工作交錯。
