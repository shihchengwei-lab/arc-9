## 材料

內部工具提供多租戶的 CSV 客戶匯入。每份檔案最多 500 筆；使用者只可讀取與匯入自己租戶的資料。租戶代號可由通訊錄看到，各租戶的檔名固定為 customers.csv。

API 已驗證登入者，從伺服器登入狀態取得 tenant_id，不接受呼叫者改寫 tenant_id。使用者在請求中提供 file_path，指向檔案服務上的 CSV。

API 對 file_path 做字串檢查：必須以 /tenants/{登入者的 tenant_id}/ 開頭；符合即建立工作，將登入者 tenant_id 與原始 file_path 一起存入不可修改的工作紀錄。工作建立後，呼叫者不能修改紀錄。

worker 使用服務帳號讀取該 file_path。檔案服務明訂：開檔前會合併重複的 /，並消去 . 與 .. 路徑段；worker 的服務帳號可以讀取 /tenants/ 下所有租戶的檔案。檔案內容在工作期間不會改變。

worker 將讀到的 CSV 匯入工作紀錄中的 tenant_id；資料庫寫入與查詢都強制使用此 tenant_id，使用者不能透過 CSV 欄位改寫租戶。匯入後，該租戶使用者可以查詢剛匯入的姓名與電話。

已處理的其他條件：新舊工作使用固定受理版本與資料庫條件更新；客戶更新及工作完成狀態同交易提交；重送已完成工作只回傳既有結果。容量足以應付本期負載，未提出效能擴充需求。
