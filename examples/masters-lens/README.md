# masters-lens：四個審查案例

四個 CSV 匯入方案，分別檢查流程結構、租戶資料隔離、過載受理與交付條件。

| 案例 | 材料與問題 | 完整回答 | 回答中的安排 |
|---|---|---|---|
| CSV 匯入 | [題目](csv/input.md) | [原文](csv/answer.md) | 將修正優先順序、重試識別、資料庫原子比較與同交易提交連在一起，先簡化流程，再驗證中斷與交錯執行。 |
| 租戶資料隔離 | [題目](security/input.md) | [原文](security/answer.md) | 沿路徑正規化、讀檔與匯入追到跨租戶外洩，改由可信租戶推導固定來源，取消呼叫者選擇原始路徑。 |
| 過載與受理 | [題目](overload/input.md) | [原文](overload/answer.md) | 由吞吐量推算等待，指出 202 與實際受理脫節；提出容量准入、拒收時收斂工作狀態、停止重複建立工作與等待期限檢查。 |
| 已完成驗證的方案 | [題目](complete/input.md) | [原文](complete/answer.md) | 對照版本、交易、重試與容量紀錄，支持按目前範圍交付。 |

[使用版本與執行紀錄](execution.md)。
