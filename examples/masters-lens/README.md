# masters-lens：四個審查案例

四個 CSV 匯入方案，分別檢查流程結構、租戶資料隔離、過載受理與交付條件。

| 案例 | 材料與問題 | 完整回答 | 回答中的安排 |
|---|---|---|---|
| CSV 匯入 | [題目](csv/input.md) | [原文](csv/answer.md) | 將新舊資料的判準、資料庫版本、條件更新與同交易提交連在一起，先確認產品語意再選擇安排。 |
| 租戶資料隔離 | [題目](security/input.md) | [原文](security/answer.md) | 沿路徑正規化、讀檔與匯入追到跨租戶外洩，改由可信租戶推導固定來源，取消呼叫者選擇原始路徑。 |
| 過載與受理 | [題目](overload/input.md) | [原文](overload/answer.md) | 由吞吐量推算等待，指出 202 與實際受理脫節；提出接收限制、同交易保存工作與待派送訊息，以及補送責任。 |
| 已完成驗證的方案 | [題目](complete/input.md) | [原文](complete/answer.md) | 對照版本、交易、重試與量測紀錄，支持按目前範圍交付，交代滿載拒收與重試方式。 |

[使用版本與執行紀錄](execution.md)。
