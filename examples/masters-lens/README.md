# masters-lens：四個審查案例

四個 CSV 匯入方案，分別檢查流程結構、租戶資料隔離、過載受理與交付條件。

| 案例 | 材料與問題 | 完整回答 | 回答中的安排 |
|---|---|---|---|
| CSV 匯入 | [題目](csv/input.md) | [原文](csv/answer.md) | 由資料庫序號與原子比較保護修正優先，固定工作輸入與重試身分，資料與完成狀態同交易提交。 |
| 租戶資料隔離 | [題目](security/input.md) | [原文](security/answer.md) | 將正規化、來源授權與 worker 讀取對象接在一起，工作只保存通過租戶驗證的正規路徑。 |
| 過載與受理 | [題目](overload/input.md) | [原文](overload/answer.md) | 推算積壓並指出 202 受理缺口，由 API 承接准入與持久化執行責任，前端查詢原工作，重試沿用同一識別。 |
| 已完成驗證的方案 | [題目](complete/input.md) | [原文](complete/answer.md) | 對照版本、交易、重試與容量紀錄，支持按目前範圍交付。 |
