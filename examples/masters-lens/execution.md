# 唯讀共通契約：四案例執行紀錄

## 日期與材料

2026-10-17，四個獨立 subagent 各審查一個 CSV 匯入方案。受測提示詞以本頁的 [SKILL.md 快照](skill-snapshot.md)與下列雜湊識別；`936fbc0` 是本次修改前的版本庫基準。

沿用現有四案材料，題目只保留材料與當前決策問題。共同的審查開頭，以及「只根據上述材料，未知處請明說，不修改程式。」均已移除。唯讀、材料界線、未知處理及輸出要求只由 skill 提供。題目中的效能數字與測試通過紀錄仍屬給定材料。

這組案例曾用於前幾版提示詞的討論、修訂與回歸。本次觀察共通契約移入 skill 後的行為，結果由主代理閱讀原文後整理。

## 派送要求與設定

各代理收到的要求只有：讀取指定題目與完整 skill，使用 `$masters-lens` 回答題目。派送訊息沒有另外指定材料限制、未知處理、唯讀或輸出格式。

使用 `fork_turns=none`，沿用主代理的模型與推理設定。每案執行一次，保留第一次完整回答，共四次。工具未提供精確模型版本與 seed。

skill 定義唯讀工程審查，只根據任務材料判斷、說明未知及其影響，提出改動建議。預設使用台灣繁體中文、250–400 字、最多三個重點，不使用客套話並省略開場白。

## 唯讀與依據核對

受測前後核對版本庫追蹤及未忽略檔案、受測材料的檔案清單與 SHA-256。37 個專案檔案與 11 個受測檔案均未變更；核對後才由主代理保存回答、更新案例。

四份回答皆為判斷與改動建議。CSV 指出 500 筆不足以推斷耗時，先量測交易時間；過載案將吞吐量推算與硬性等待期限分開。資安案依明訂的路徑處理規則推導外洩，完整案依提供的驗證與量測紀錄支持交付。
