# 共通輸出契約：四案例執行紀錄

## 日期與材料

2026-10-17，使用 `14fcf3f` 的 [SKILL.md 快照](skill-snapshot.md)，四個獨立 subagent 各審查一個 CSV 匯入方案。

沿用現有四案材料，從題目移除語言、字數、重點數、開場白，以及「判斷、理由、下一步」的重複要求。這些輸出要求只由 skill 提供。題目中的效能數字與測試通過紀錄仍屬給定材料。

這組案例曾用於前幾版提示詞的討論、修訂與回歸。本次觀察加入共通契約後的預設輸出，結果由主代理閱讀原文後整理。

## 派送要求與設定

各代理收到的要求是：讀取指定題目與完整 skill，使用 `$masters-lens` 回答題目；只使用這兩份檔案，不修改檔案。派送訊息沒有額外輸出限制。

使用 `fork_turns=none`，沿用主代理的模型與推理設定。每案執行一次，保留第一次完整回答，共四次。工具未提供精確模型版本與 seed。

skill 的預設是台灣繁體中文、250–400 字、最多三個重點，不使用客套話並省略開場白；回答內容為整體判斷、關鍵依據與必要的下一步。

四份回答都使用繁體中文、符合字數範圍，並直接從判斷開始。CSV 與過載可直接核對三個條列；另兩份以段落作答。段落數與重點數分開記錄，「最多三點」沒有統一的可計數呈現，本輪不將這項記為已通過機械檢查。

字元計法沿用前次：去除空白、清單標記、粗體與行內程式標記，保留標點、英文字母與數字。

## 內容觀察

CSV 仍提出優先序、原子比較與同交易提交；租戶隔離仍以可信租戶決定來源。過載案保留積壓估算、受理缺口、重送與期限處理，但這次沒有展開前次的工作／待派送訊息同交易保存安排。完整案仍支持交付，另交代未直接檢查程式或重跑測試的判斷範圍。

四份回答皆保留原文，沒有逐位大師報告；完整案沒有新增交付阻塞。測試後保持提示詞原狀。
