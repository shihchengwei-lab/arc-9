# masters-lenses

[English](README.en.md)

`$masters-lens` 是手動呼叫的唯讀工程審查 skill。它依任務提供或允許讀取的材料，從交付結果回推必要條件、沿具體操作追查成因，以「使非法狀態無法被表達」為最高原則，提出整體判斷、關鍵依據與必要的改動建議。

## 實際案例

以下四個 CSV 匯入案例，分別涉及流程結構、租戶隔離、受理容量與交付條件。

| 題目中的方案 | 本次回答 |
|---|---|
| 每週約兩次、每次最多 500 筆的 CSV 匯入，預留多格式工廠並加入佇列；舊工作可能覆寫修正資料。 | 不宜直接實作。先保留 CSV 解析、匯入服務與資料庫，工作固定綁定內容，客戶更新與完成狀態同交易提交。先定義「較新」；若依受理順序，由資料庫分配序號並原子限制覆寫。量測後再決定是否背景執行。 |
| 租戶只能匯入自己的檔案，API 卻接受路徑字串，檔案服務再正規化路徑。 | 指出路徑穿越會讓 worker 讀取其他租戶檔案，再匯入呼叫者租戶供查詢。取消呼叫者指定任意路徑，由可信租戶與固定檔名推導來源。 |
| 每秒到達 20 個工作、完成 2 個，要求等待不超過 30 秒；提案只擴大佇列。 | 否決單純擴容。API 接納時原子保留容量，超額拒收；工作與待送訊息同交易保存，由補送程序恢復派送。前端追蹤原工作並使用冪等重試，服務須讓工作在 30 秒內啟動或明確失敗。 |
| 單一 CSV 流程已具備版本、交易、重試與容量控制，題目提供的驗證紀錄均符合需求。 | 支持本期交付，以入口驗證、固定內容與版本、資料庫鎖定及原子更新、同交易結果與恢復，以及既有量測說明理由。沒有實質新增問題。 |

[完整題目與回答](examples/masters-lens/README.md)。

## 使用

共用契約集中輸入、輸出、證據與候選安排的承接。九位大師的具名場景提供不同觀察方法，依當前問題選用；候選改變時，重檢依賴被改動部分的流程與判斷。完整方法見 [SKILL.md](dist/skills/masters-lens/SKILL.md)。

安裝後，在目前的任務討論中呼叫：

```text
$masters-lens 請檢查目前方案有哪些必要改動。
```

明確指定輸出語言時依指定回答；未指定時，跟隨使用者本次請求的主要語言與書寫形式。中文預設 250–400 個正文字元，英文預設 150–250 詞，全文最多三個條列項目，交代判斷、依據，以及影響決策的未知與必要下一步，不寫客套話或開場白。本次任務可指定其他輸出要求；計數與省略條件見 [skill 共通契約](dist/skills/masters-lens/SKILL.md)。

[中文請求、英文請求與指定語言覆寫的完整回答及執行紀錄](examples/masters-lens/language/README.md)。

## 安裝

[下載 ZIP](dist/masters-lenses.zip)，解壓縮後將 `masters-lens` 資料夾放入 Codex 的 skills 目錄。Windows 預設位置為 `C:\Users\<使用者名稱>\.codex\skills\`；已設定 `CODEX_HOME` 時，使用該目錄下的 `skills`。下個回合即可呼叫 `$masters-lens`。

也可以直接提供 [SKILL.md](dist/skills/masters-lens/SKILL.md) 的檔案路徑，請模型讀取並使用。
