# arc-9

[English](README.en.md)

方案看起來能用，仍可能讓舊資料覆蓋修正、讀到別人的檔案，或在中斷重試時出錯。

`$arc9` 是在 Codex 中手動呼叫的審查工具。它沿資料與操作追查問題，指出方案是否符合需求、哪裡必須改，以及原因。方案已符合需求時，也會直接說明。

審查優先尋找能從資料、權限與操作安排上避免錯誤的改法。審查者在獨立的 Codex CLI 程序查證，唯讀沙箱會阻止檔案寫入。

## 代表案例

四個 CSV 匯入案例的[完整題目與回答](examples/csv-import/README.md)。

| 題目中的方案 | 審查指出什麼 |
|---|---|
| 少量匯入先加了多格式支援與佇列。舊工作重試可能覆蓋後來的修正。 | 先決定哪次更新優先，讓資料寫入與完成紀錄一致。是否需要背景處理，留待量測。 |
| 系統檢查有權存取的目錄，開檔時卻可能繞到其他人的目錄。 | 由登入租戶決定實際開啟的檔案，並處理仍保存舊路徑的待執行工作。 |
| 每秒收到 20 件工作，只能完成 2 件，卻承諾等待不超過 30 秒。 | 依可用處理能力限制接單，只有可靠接下的工作才回覆已受理。 |
| 需求接受重送覆寫，也要求每份 CSV 有 1–500 筆。 | 接受既定覆寫規則。現有紀錄尚未證明會拒絕 0 或 501 筆，因此還不能確認可交付。 |

## 開始使用

需要可執行終端指令的 Codex 環境，以及已登入的 Codex CLI。Windows 需先完成 Codex 的沙箱設定。

1. [下載 ZIP](dist/arc-9.zip)，解壓縮後將 `arc9` 資料夾放入 Codex 的 skills 目錄。Windows 預設位置為 `C:\Users\<使用者名稱>\.codex\skills\`。若曾用 `CODEX_HOME` 指定其他 Codex 資料目錄，則使用該目錄下的 `skills`。
2. 下個回合，在目前的任務討論中呼叫：

```text
$arc9 請檢查目前方案有哪些必要改動。
```

回答會說明判斷、理由與下一步，區分需要修改的地方和需要查證的事項。預設沿用請求的語言，也可指定語言或篇幅。

也可提供 [SKILL.md](dist/skills/arc9/SKILL.md) 的完整路徑，請模型讀取並使用；須保留完整的 `arc9` 資料夾，包含其中的 `references`。

重建與測試請見[維護說明](MAINTENANCE.md)。
