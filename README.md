# masters-lenses

`$masters-lens` 是手動呼叫的工程判斷 skill。它從交付結果回推必要條件，沿具體操作追查成因，以「使非法狀態無法被表達」為最高原則，提出有依據的整體判斷與改動安排。

## 實際案例

以下四個 CSV 匯入案例，分別涉及流程結構、租戶隔離、受理容量與交付條件。

| 題目中的方案 | 本次回答 |
|---|---|
| 每週約兩次、每次最多 500 筆的 CSV 匯入，預留多格式工廠並加入佇列；舊工作可能覆寫修正資料。 | 不宜直接實作。先保留單一 CSV 流程，提出固定工作版本、資料庫條件更新與資料／完成狀態同交易提交，再量測是否需要背景執行。 |
| 租戶只能匯入自己的檔案，API 卻接受路徑字串，檔案服務再正規化路徑。 | 推導出跨租戶讀取、匯入後供查詢的外洩路徑；建議由可信租戶推導固定來源，取消呼叫者選擇原始路徑。 |
| 每秒到達 20 個工作、完成 2 個，要求等待不超過 30 秒；提案只擴大佇列。 | 否決單純擴容，提出接收限制與拒收、工作與待投遞訊息同交易保存、補送程序，以及沿用工作識別重試。 |
| 單一 CSV 流程已具備版本、交易、重試與容量控制，題目提供的驗證紀錄均符合需求。 | 支持按目前範圍交付，說明既有機制如何守住承諾，保留測試與操作說明。 |

[完整題目與回答](examples/masters-lens/README.md)。

## 使用

安裝後，在目前的任務討論中呼叫：

```text
$masters-lens 請檢查目前方案有哪些必要改動，根據現有材料說明理由。先不要修改檔案。
```

## 安裝

[下載 ZIP](dist/masters-lenses.zip)，解壓縮後將 `masters-lens` 資料夾放入 Codex 的 skills 目錄。Windows 預設位置為 `C:\Users\<使用者名稱>\.codex\skills\`；已設定 `CODEX_HOME` 時，使用該目錄下的 `skills`。下個回合即可呼叫 `$masters-lens`。

也可以直接提供 [SKILL.md](dist/skills/masters-lens/SKILL.md) 的檔案路徑，請模型讀取並使用。
