# masters-lenses

`$masters-lens` 是手動呼叫的唯讀工程審查 skill。它依任務提供或允許讀取的材料，從交付結果回推必要條件、沿具體操作追查成因，以「使非法狀態無法被表達」為最高原則，形成判斷、說明未知並提出具體改動建議。

## 實際案例

以下四個 CSV 匯入案例，分別涉及流程結構、租戶隔離、受理容量與交付條件。

| 題目中的方案 | 本次回答 |
|---|---|
| 每週約兩次、每次最多 500 筆的 CSV 匯入，預留多格式工廠並加入佇列；舊工作可能覆寫修正資料。 | 不宜照案實作。移除格式工廠與策略，以工作版本和資料庫原子比較保護修正，客戶更新與工作完成狀態同交易提交；先量測再決定是否背景執行。 |
| 租戶只能匯入自己的檔案，API 卻接受路徑字串，檔案服務再正規化路徑。 | 推導出跨租戶資料外洩；取消呼叫者提供路徑，讓 worker 依已確認的租戶身分，透過受租戶約束的開檔操作讀取固定檔案。 |
| 每秒到達 20 個工作、完成 2 個，要求等待不超過 30 秒；提案只擴大佇列。 | 否決單純擴容，將容量與截止時間納入接單；工作與待送事件同交易保存，前端追蹤原工作、重送去重，到期失敗後禁止執行。 |
| 單一 CSV 流程已具備版本、交易、重試與容量控制，題目提供的驗證紀錄均符合需求。 | 支持按目前範圍交付，以版本、交易、重試與容量紀錄說明理由。 |

[完整題目與回答](examples/masters-lens/README.md)。

## 使用

安裝後，在目前的任務討論中呼叫：

```text
$masters-lens 請檢查目前方案有哪些必要改動。
```

預設用台灣繁體中文回答 250–400 個字元，全文最多三個條列項目，交代判斷、依據，以及影響決策的未知與必要下一步，不寫客套話或開場白。本次任務可指定其他輸出要求；計數與省略條件見 [skill 共通契約](dist/skills/masters-lens/SKILL.md)。

## 安裝

[下載 ZIP](dist/masters-lenses.zip)，解壓縮後將 `masters-lens` 資料夾放入 Codex 的 skills 目錄。Windows 預設位置為 `C:\Users\<使用者名稱>\.codex\skills\`；已設定 `CODEX_HOME` 時，使用該目錄下的 `skills`。下個回合即可呼叫 `$masters-lens`。

也可以直接提供 [SKILL.md](dist/skills/masters-lens/SKILL.md) 的檔案路徑，請模型讀取並使用。
